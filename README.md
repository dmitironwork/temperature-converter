# TemperatureConverter

Консольна Java-програма для конвертації температури між Цельсієм (C), Фаренгейтом (F) і Кельвіном (K)

## Вимоги

Потрібна встановлена Java (JRE або JDK), версія 17 чи новіше.

## Як запустити

Відкрити термінал, перейти в папку з файлом `TemperatureConverter.jar` і виконати:

```
java -jar TemperatureConverter.jar
```

## Як користуватись

Програма попросить:
1. Ввести одиницю, ІЗ ЯКОЇ конвертувати: `C`, `F` або `K` (або `E`, щоб вийти з програми)
2. Ввести одиницю, У ЯКУ конвертувати: `C`, `F` або `K`
3. Ввести саме значення температури (число)

## Формули конвертації

- Celsius → Fahrenheit: `F = C * 9/5 + 32`
- Fahrenheit → Celsius: `C = (F - 32) * 5/9`
- Celsius → Kelvin: `K = C + 273.15`
- Kelvin → Celsius: `C = K - 273.15`
- Fahrenheit ↔ Kelvin рахуються через проміжний перехід у Celsius.
